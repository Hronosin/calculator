# Engineering Calculator — Modular Edition

> Кроссплатформенный инженерный калькулятор, который умеет вычислять, **символьно интегрировать, рисовать графики со слайдерами, конвертировать ~370 единиц от планковского времени до возраста Вселенной, и выглядит круто в восьми темах включая «Строгая Серьозность».**

├──────┬─────────────────────────────────────────┬─────────────────┤
│  ⌗   │              42                         │ History         │

## ✨ Что умеет

### Шесть киллер-фич

| | Фича | Подробнее |
|---|---|---|
| 🧠 | **Символьная математика** | Производные, интегралы, упрощение, разложение на множители, решение уравнений. Считает прямо в браузере через `algebrite` — без сервера, без Pyodide |
| 🔌 | **Плагины** | Кидаешь `.js`-файл в `plugins/` — появляется новая формула или вкладка. Без перекомпиляции. Можно установить плагин прямо из UI вставкой кода |
| 📐 | **LaTeX-рендер + экспорт** | Все формулы отрисовываются красиво через KaTeX. Сессию можно выгрузить в Markdown или PDF одной кнопкой |
| ⌘ | **Командная палитра** | `Ctrl+K` / `⌘K` — мгновенный поиск по 180 формулам, 35 конвертерам, истории и действиям. Регистронечувствительный fuzzy-поиск |
| 📊 | **Графики 2D со слайдерами** | Меняешь параметры `a, b, c` мышью — кривая `y = a·sin(b·x + c)` перестраивается в реальном времени |
| ⌨ | **Встроенный REPL** | Полноценный JS-скриптинг с доступом к `history`, `memory`, `ans`, всем формулам и конвертерам через API. Стрелочки ↑↓ — навигация по истории команд |

### Базовые возможности

- **Калькулятор** с автопоиском по 80+ операциям, режимами DEG/RAD/GRAD, INV-модификатором, памятью M+/M-/MR/MC, `ans`
- **Конвертер** с 35 категориями и ~370 единицами
- **Браузер формул** — 180 формул в 23 категориях с понятным вводом параметров
- **История** с автосохранением, экспортом, фильтрацией, кликом для возврата
- **Темы** (8 шт.) + **языки** (11 шт.) — переключение в шапке
- **Persistence** — история, память, тема, язык, плагины автоматически сохраняются в `localStorage`

## 🏗 Архитектура и технические приколы

### Чистое разделение `core/` ↔ `ui/`

```
src/
├── core/              💎 ноль зависимостей от React и DOM
│   ├── types.ts          Общие типы (HistoryEntry, Formula, Converter, ...)
│   ├── evaluator.ts      Парсер арифметики на mathjs
│   ├── symbolic.ts       Algebrite-обёртка
│   ├── history.ts        Observable store с persistence
│   ├── memory.ts         M+/M-/MR/MC
│   ├── plotting.ts       Function-plot обёртка
│   ├── formulas/         23 модуля формул + реестр
│   └── converters/       35 модулей конвертеров + реестр
├── i18n/              🌍 локализация
│   ├── index.ts          LocaleManager с 11 локалями
│   ├── locales/*.json    UI-переводы
│   ├── dictionaries.ts   Темы, категории, имена формул и конвертеров
│   └── dictionaries-extra.ts  Расширение словарей через registerConverterNames
├── plugins/           🔌 динамическая загрузка плагинов
│   └── PluginManager.ts  import.meta.glob + installFromSource(blob URL)
├── ui/                🎨 React-компоненты
│   ├── theme.tsx         8 тем через data-theme + CSS-переменные
│   ├── styles/global.css 13 CSS-переменных drive everything
│   └── components/       Calculator, Display, Keypad, CommandPalette, ...
├── utils/
│   ├── storage.ts        LocalStorage / Tauri FS — swappable
│   └── export.ts         Markdown / PDF (через окно печати браузера)
├── App.tsx
└── main.tsx           ⚡ оркестрация: CSS → реестры → формулы → конвертеры → React
```

Принцип: **`core/` можно протестировать в Node без браузера, переиспользовать в CLI, подключить к боту**. Сегодня React, завтра Telegram, послезавтра CLI — логика одна.

### Registry-паттерн — добавление = одна строка

Каждый домен формул и каждая категория конвертеров — это самостоятельный модуль, который вызывает `register()` при импорте. Чтобы добавить новую категорию формул:

```typescript
// src/core/formulas/oceanography.ts
import { register } from './registry';

register({
  id: 'ocean.salinity-density',
  name: 'Плотность морской воды',
  category: 'Океанография',
  expression: 'ρ = 1000 + 0.8·S − 0.2·T',
  inputs: [
    { name: 'S', label: 'Солёность', unit: 'PSU', default: 35 },
    { name: 'T', label: 'Температура', unit: '°C', default: 15 },
  ],
  compute: ({ S, T }) => ({
    result: 1000 + 0.8 * S - 0.2 * T,
    unit: 'кг/м³',
    latex: `\\rho = 1000 + 0.8 S - 0.2 T`,
  }),
});
```

И добавить `import './core/formulas/oceanography';` в `main.tsx`. **Всё.** UI ничего не трогаешь — формула появится в реестре, в командной палитре, в списке формул.

### Плагины как ES-модули

В отличие от старого PyQt5-калькулятора с `exec()`, плагины здесь — это полноценные ES-модули, загружаемые через `import.meta.glob` (build-time) или `URL.createObjectURL(blob)` + dynamic `import()` (runtime).

```javascript
// plugins/my-plugin.js
export default {
  id: 'my-plugin',
  name: 'Мой плагин',
  formulas: [{
    id: 'my.something',
    name: 'Что-то',
    category: 'Своё',
    inputs: [{ name: 'x', label: 'X', default: 1 }],
    compute: ({ x }) => ({ result: x * 2, latex: `2x = ${2*x}` }),
  }],
};
```

Кидаешь файл в `plugins/` → Vite подхватит → формула появится при следующем `npm run dev`. Из UI можно вставить код и установить runtime — он попадёт в blob URL и подгрузится через native `import()`.

### Темы через `data-theme` + CSS variables

Никаких CSS-in-JS, никакого пересчёта стилей. 8 тем — это 8 блоков `:root[data-theme="..."]` в CSS с 13 переменными:

```css
:root[data-theme='matrix'] {
  --bg: #000000;
  --text: #00ff41;
  --accent: #00ff41;
  /* ... */
}
```

Переключение темы = `document.documentElement.setAttribute('data-theme', 'matrix')`. Всё остальное — `transition: background 240ms ease` на body.

Добавление новой темы — одна строка в массив `THEMES` + один CSS-блок.

### i18n с многоуровневыми словарями

Локали разделены по назначению:

- `locales/*.json` — короткие переводы UI (~30 ключей)
- `dictionaries.ts` — большие словари (темы, 23 категории, 180 имён формул, 16 имён конвертеров)
- `dictionaries-extra.ts` — расширение словарей через `registerConverterNames()`, чтобы не переписывать главный файл при добавлении новых конвертеров

Fallback chain: `текущая локаль → en → исходная строка из кода`. Никогда не падает, всегда что-то покажет.

### Persistence через swappable backend

```typescript
interface StorageBackend {
  get<T>(key: string): Promise<T | null>;
  set(key: string, value: unknown): Promise<void>;
  remove(key: string): Promise<void>;
}
```

Сейчас используется `LocalStorageBackend`. На Tauri можно подменить на `TauriFSBackend` без изменений в потребителях.

### REPL с реальным доступом к runtime

В REPL доступны:

```javascript
evaluate('2 + 2')              // -> { ok: true, value: '4', latex: '4', raw: 4 }
history.list()                 // -> массив HistoryEntry
history.list().map(e => e.result).reduce((a,b) => a + Number(b), 0)
memory.get()                   // -> текущее значение памяти
memory.add(10)
formulas.all()                 // -> все 180 формул
formulas.get('phys.kinetic-energy').compute({ m: 1, v: 10 })
ans()                          // -> последний результат
```

Это не sandbox-эмуляция, а **реальные ссылки** на singleton-сторы. Можно писать сложные пайплайны.

## 🙋 FAQ

**Q: А где Python? Старый калькулятор же на PyQt5 был.**
A: PyQt5 не работает в браузере и на мобильных. Один TypeScript-codebase покрывает все 6 платформ. Все формулы из `extended_mode.py` перенесены 1:1 в `core/formulas/`, плюс добавлено ~150 новых.

**Q: Почему не Electron?**
A: Electron-приложение для калькулятора весит ~120 МБ и ест ~300 МБ RAM. Tauri — 10 МБ / 30 МБ. Разница принципиальная.

**Q: Можно ли использовать без интернета?**
A: Да. Web-версия — это PWA, после первой загрузки работает оффлайн. Desktop/mobile-версии вообще не нужен интернет.

**Q: Можно ли добавить свою формулу/конвертер без знания React?**
A: Да. Пишешь обычный JS-файл по схеме плагина (см. выше) — кидаешь в `plugins/` — готово.

**Q: Зачем винные бутылки, скорость улитки и Big Mac Index в инженерном калькуляторе?**
A: А почему нет.
